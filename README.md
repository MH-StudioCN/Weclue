## 项目简介

微信官方帮助中心明确写道：聊天记录不上传服务器，官方功能**无法导出聊天记录**（仅支持朋友圈、收藏与账号信息）。微刻录补的就是这一块——

> 读取电脑本地保存的微信数据，在本机完成解密与解析，把聊天记录、朋友圈、收藏、通讯录一次全导出来。

- 数据处理全程在本地完成，不与微信服务器交互，不上传聊天数据；
- 自动识别本机微信、自动解密数据库与图片密钥，无需手动配置、无需脚本；
- 面向个人用户的桌面工具，界面基于 Tauri 2.0，启动快、内存占用低。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 聊天记录备份 | 按联系人 / 群聊读取完整对话，支持时间范围与媒体类型筛选，离线浏览不回源 |
| 朋友圈记录备份 | **无需事先翻阅、无需手动同步**，选中好友即可一键导出全部可见动态；图文、视频、实况照片、评论点赞完整留存 |
| 微信收藏导出 | 图片、视频、语音、文件、链接、公众号文章、笔记、聊天记录等 15 类收藏一键归档，媒体按需下载 |
| 联系人导出 | 按「全部 / 标签 / 群聊 / 曾经的好友」分类筛选，导出备注、标签、微信号、签名等完整资料 |
| 丰富消息类型 | 图片、视频、语音（自动转 WAV）、文件、表情、红包、转账、名片、笔记、通话、引用、小程序等均可解析 |
| 按需筛选 | 今天 / 昨天 / 最近 7 天 / 本月 / 本年 / 全部快捷时间，配合关键词与内容类型，只导所需 |
| 增量 · 批量 · 去重 | 支持增量备份与多对象批量导出，重复数据自动去重，再次导出智能识别已有文件 |

## 导出格式一览

| 数据类型 | 可用格式 |
| --- | --- |
| 聊天记录 | HTML、JSON |
| 朋友圈 | HTML、JSON、DOC |
| 微信收藏 | HTML、JSON |
| 联系人（通讯录） | JSON、CSV |

HTML 即开即看；JSON 适合留档与二次处理；CSV 可直接用 Excel 打开；DOC 适合朋友圈留存与打印。

## 三步上手

1. **选择导出对象**：在「选择导出对象」中挑选联系人 / 群聊，分别加入「聊天导出列表」或「朋友圈导出列表」。
2. **一键导出**：选好对象、时间范围与格式即可开始导出；朋友圈无需先翻阅或同步，一键导出全部可见动态。
3. **本地留存**：导出的 JSON / HTML / CSV / DOC 保存在你指定的目录，随时浏览、整理或继续增量备份。

> 首次启动会自动完成：微信进程检测 → 登录状态检测 → 数据库密钥检测 → 图片密钥检测 → 本地解密，全程引导式操作。

## 隐私与安全

- **不上传数据**：聊天数据与用户信息全程留在本机，不做任何上传；
- **本机解密 · 离线可用**：数据库与媒体文件在本机解密，浏览、预览与导出都无需联网；
- **只读本地已有数据**：仅读取电脑本地仍存在的内容，不联网抓取，也不触碰云端；
- **导出位置自选**：导出文件的保存位置由你决定，随时存取、自由整理。

## 常见问题

<details>
<summary><b>导出聊天记录的原理是什么？</b></summary>

微刻录读取电脑本地保存的微信数据，在本机完成解密与解析，并导出记录原文。读取过程不与微信服务器交互，也不会上传聊天数据。
</details>

<details>
<summary><b>会上传我的微信聊天记录吗？</b></summary>

不会。软件不上传聊天数据或用户信息；联网仅用于必要的登录验证、更新和下载组件，数据始终留在本机。
</details>

<details>
<summary><b>使用会封号吗？</b></summary>

从原理上分析，微刻录只是复制本机微信的本地数据库并解密读取数据，不与微信服务器交互、不修改任何微信数据，不会对账号造成安全方面的影响。新注册账号只要能在电脑微信上正常登录，同样可以使用。
</details>

<details>
<summary><b>微信里看不到的聊天记录或图片可以查看吗？</b></summary>

不可以。微刻录只能查看电脑本地仍然存在的聊天记录与媒体文件，本地已清理的内容无法恢复。
</details>

<details>
<summary><b>支持哪些版本的微信？</b></summary>

支持 PC 版微信，当前已适配最新 **4.2.0.53**。微信新版本发布后，适配数据通过服务端热更新下发，通常无需等待软件发版；若个别版本暂未适配，请耐心等待适配完成。
</details>

<details>
<summary><b>支持企业微信吗？</b></summary>

暂不支持。目前仅支持个人（普通）微信，企业微信的本地数据结构不同，暂未适配。
</details>

<details>
<summary><b>朋友圈可以导出私密内容吗？</b></summary>

软件里登录的账号可以导出自己账号的全部朋友圈（包括仅自己可见的内容）；导出好友朋友圈时，只能导出你在微信里能看到的内容。
</details>

更多教程与指南见官网：[weikelu.cn/tutorials.html](https://weikelu.cn/tutorials.html)。
